# Getting started with crypto-market-data

Live cryptocurrency and DeFi market dashboard with data from CoinGecko and DeFiLlama

## Install

```bash
npm install
```

## Verify the install

Clone the repository and run its checks to confirm everything works on your machine:

```bash
git clone https://github.com/nirholas/crypto-market-data.git
cd crypto-market-data
```

Available commands:

| Command | Runs |
|---|---|
| `npm run dev` | `vite` |
| `npm run build` | `tsc && vite build` |
| `npm run lint` | `eslint . --ext ts,tsx --report-unused-disable-directives --max-warnings 20` |
| `npm run test` | `vitest` |
